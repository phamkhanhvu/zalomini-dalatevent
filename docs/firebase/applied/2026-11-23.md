# Rules đang chạy trên Firebase (đọc từ Console ngày 23.11.2026)

Kết luận sau khi đọc rules thật: rules sẵn có của dự án đã đóng mặc định và đúng với cách trò chơi đọc/ghi, nên KHÔNG thay bằng bản soạn trong thư mục này (bản soạn Firestore chưa chạy thử được, thay vào có thể làm hỏng trò chơi đang chạy mà lợi ích ít). Realtime Database: giữ nguyên, không sửa gì.

Thay đổi duy nhất, đã Publish ngày 23.11.2026: thêm khối `plans/{uid}` vào Firestore để lưu lịch trình của web/app. Hai khối `saves` và `board` giữ nguyên từng chữ.

## Firestore sau khi thêm

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /saves/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
    match /board/{uid} {
      allow read: if true;
      allow write: if request.auth != null && request.auth.uid == uid;
    }
    // Lich trinh DalatEvent cua tung nguoi (web/app): chi chinh chu doc va ghi.
    match /plans/{uid} {
      allow read, delete: if request.auth != null && request.auth.uid == uid;
      allow create, update: if request.auth != null && request.auth.uid == uid
        && request.resource.data.keys().hasOnly(['programIds', 'items', 'updatedAt'])
        && request.resource.data.programIds is list
        && request.resource.data.programIds.size() <= 100
        && request.resource.data.items is list
        && request.resource.data.items.size() <= 100;
    }
  }
}
```

Quay lui: xóa khối `match /plans/{uid} { … }` rồi Publish (hoặc chọn bản trước trong lịch sử rules của Console).

## Đã kiểm tra sau khi Publish
- Không đăng nhập: đọc `board` được (200), đọc `plans/…` và `saves/…` bị từ chối (403).
- Trò chơi không bị đổi rule nào.
